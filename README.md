# Homebrew Tap for [Brow](https://brow-app.com)

**[https://brow-app.com](https://brow-app.com)** — Free all-in-one Mac productivity app. Replaces your launcher, clipboard manager, window manager, screenshot tool, and 20+ more utilities.

## Install

```bash
brew tap Mac-Brow-App/tap
brew install --cask brow
```

## Update

```bash
brew upgrade --cask brow
```

## Uninstall

```bash
brew uninstall --cask brow
```

## About

[Brow](https://brow-app.com) is a free all-in-one Mac productivity app — launcher, clipboard manager, window manager, screenshots, system cleanup, and 20+ more tools in one native app.
